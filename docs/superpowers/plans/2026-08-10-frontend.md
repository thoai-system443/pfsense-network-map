# pfSense Network Map — Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Prerequisite:** Backend plan (`2026-08-10-backend.md`) hoàn thành và API chạy được. Frontend gọi thẳng các endpoint đã có ở đó.

**Goal:** SPA tĩnh, chạy offline, cho phép nạp file backup pfSense rồi xem bản đồ topology, bản đồ luồng truy cập, tra cứu hai chiều, và liệt kê toàn bộ đối tượng.

**Architecture:** Vite build ra `dist/` tĩnh, nginx serve. Không có node runtime trong production. `API_URL` đọc lúc chạy từ `window.__CONFIG__` do entrypoint ghi vào `config.js`, nên đổi địa chỉ backend không cần build lại. Mọi trạng thái server do TanStack Query giữ; `config_id` giữ trong URL để refresh không mất ngữ cảnh.

**Tech Stack:** Vite, React 18, TypeScript strict, Tailwind, shadcn/ui, Magic UI, TanStack Query, react-router, react-hook-form + zod, `@xyflow/react`, Vitest + Testing Library.

## Global Constraints

- **Offline tuyệt đối.** Không CDN font, không icon từ mạng, không map tile. Mọi asset nằm trong `dist/`. Font tự host trong `public/fonts/`.
- **Không nginx proxy sang backend.** SPA gọi thẳng `API_URL`; CORS do backend xử lý.
- **`API_URL` chỉ đọc lúc runtime** từ `window.__CONFIG__`. Không được `import.meta.env.VITE_API_URL` cho giá trị này — làm vậy sẽ nhúng cứng vào bundle và phá yêu cầu đổi URL không rebuild.
- **`tsconfig.json` bật `strict: true`.** Không dùng `any` cho dữ liệu API; khai báo type tường minh trong `src/lib/types.ts`.
- **Mọi `<button>` trong `<form>` phải có `type` tường minh.**
- **Magic UI dùng tiết chế.** Bảng dữ liệu giữ tĩnh, không animation.
- Ngôn ngữ giao diện: tiếng Anh, khớp với dữ liệu backend trả về.

```ts
/**
```

`frontend/nginx/entrypoint.sh`:

```sh
#!/bin/sh
set -e

: "${API_URL:=http://localhost:8010}"

# Escape backslash then quote so an API_URL containing either cannot break out
# of the JavaScript string literal.
escaped=$(printf '%s' "$API_URL" | sed -e 's/\\/\\\\/g' -e 's/"/\\"/g')
printf 'window.__CONFIG__ = { API_URL: "%s" };\n' "$escaped" \
    > /usr/share/nginx/html/config.js

exec nginx -g 'daemon off;'
```

`frontend/nginx/nginx.conf`:

```ts
import { apiUrl } from "./config";
import type {
  AccessEdge,
  Alias,
  CheckResult,
  ConfigMeta,
  FilterRule,
  GraphNode,

  NatConfig,
  Region,
  SourceRegion,
  TopologyEdge,

const base = `${apiUrl}/api/v1`;

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const response = await fetch(`${base}${path}`, init);
  const body = await response.json().catch(() => ({}));
  if (!response.ok) {
    const detail = (body as { detail?: string }).detail;
    throw new Error(detail ?? `request failed with status ${response.status}`);
  }
  return body as T;
}

function postJson<T>(path: string, payload: unknown): Promise<T> {
  return request<T>(path, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload),
  });
}

export function uploadConfig(file: File): Promise<ConfigMeta> {
  const form = new FormData();
  form.append("file", file);
  return request<ConfigMeta>("/configs", { method: "POST", body: form });
}

export const getConfigMeta = (id: string) => request<ConfigMeta>(`/configs/${id}`);
export const getInterfaces = (id: string) => request<Interface[]>(`/configs/${id}/interfaces`);

  request<Alias[]>(`/configs/${id}/aliases?resolved=${resolved}`);
export const getRules = (id: string, iface?: string) =>
  request<FilterRule[]>(`/configs/${id}/rules${iface ? `?interface=${iface}` : ""}`);
export const getNat = (id: string) => request<NatConfig>(`/configs/${id}/nat`);
```

```ts
import type { GraphNode } from "@/lib/types";

const RADIUS = 320;

export interface Position {
  x: number;
  y: number;
}

/**
 * Both graphs are small — a firewall with a handful of zones — so a ring around
 * an optional centre reads better than a hierarchical layout and avoids pulling
 * in a layout library.
 */
export function radial(nodes: GraphNode[], centreId: string | null): Record<string, Position> {
  const positions: Record<string, Position> = {};
  const ring = nodes.filter((node) => node.id !== centreId);

  if (centreId && nodes.some((node) => node.id === centreId)) {
    positions[centreId] = { x: 0, y: 0 };
  }

  ring.forEach((node, index) => {
    const angle = (2 * Math.PI * index) / Math.max(ring.length, 1) - Math.PI / 2;
    positions[node.id] = {
      x: Math.round(Math.cos(angle) * RADIUS),
      y: Math.round(Math.sin(angle) * RADIUS),
    };
  });

  return positions;
}
```

```tsx
import { useMutation } from "@tanstack/react-query";
import { useState } from "react";
import { useParams } from "react-router-dom";

import { queryCheck, queryFrom, queryTo } from "@/lib/api";
import type { CheckResult, Region, SourceRegion } from "@/lib/types";

type Tab = "check" | "from" | "to";

const TABS: { id: Tab; label: string }[] = [
  { id: "check", label: "Path check" },
  { id: "from", label: "From" },
  { id: "to", label: "To" },
];

const VERDICT_STYLE: Record<string, string> = {
  pass: "text-emerald-600",
  block: "text-red-600",
  reject: "text-amber-600",
};

export function SearchPage() {
  const { configId = "" } = useParams<{ configId: string }>();
  const [tab, setTab] = useState<Tab>("check");
  const [source, setSource] = useState("");
  const [destination, setDestination] = useState("");
  const [port, setPort] = useState("");
  const [protocol, setProtocol] = useState("tcp");

  const check = useMutation<CheckResult, Error>({
    mutationFn: () =>
      queryCheck(configId, {
        source,
        destination,
        port: port ? Number(port) : null,
        protocol,
      }),
  });
  const from = useMutation<Region[], Error>({
    mutationFn: () => queryFrom(configId, { source, protocol }),
  });
  const to = useMutation<SourceRegion[], Error>({
    mutationFn: () =>
      queryTo(configId, { destination, port: port ? Number(port) : null, protocol }),
  });

  const active = tab === "check" ? check : tab === "from" ? from : to;

  return (
    <div className="space-y-6">
      <h1 className="text-xl font-semibold">Search</h1>

      <div role="tablist" className="flex gap-2 border-b">
        {TABS.map((item) => (
          <button
            key={item.id}
            type="button"
            role="tab"
            aria-selected={tab === item.id}
            className={`px-4 py-2 text-sm ${
              tab === item.id ? "border-b-2 font-medium" : "opacity-70"
            }`}
            onClick={() => setTab(item.id)}
          >
            {item.label}
          </button>
        ))}
      </div>

      <form
        className="flex flex-wrap items-end gap-4"
        onSubmit={(event) => {
          event.preventDefault();
          active.mutate();
        }}
      >
        {tab !== "to" && (
          <Field label="Source" value={source} onChange={setSource} placeholder="IP, CIDR, alias, or interface" />
        )}
        {tab !== "from" && (
          <Field label="Destination" value={destination} onChange={setDestination} placeholder="IP, CIDR, alias, or interface" />
        )}
        {tab !== "from" && <Field label="Port" value={port} onChange={setPort} placeholder="443" />}
        <label className="text-sm">
          <span className="block pb-1">Protocol</span>
          <select
            className="rounded-md border px-2 py-1"
            value={protocol}
            onChange={(event) => setProtocol(event.target.value)}
          >
            {["any", "tcp", "udp"].map((item) => (
              <option key={item} value={item}>
                {item}
              </option>
            ))}
          </select>
        </label>
        <button type="submit" className="rounded-md border px-4 py-1.5 text-sm">
          {tab === "check" ? "Check" : "Explore"}
        </button>
      </form>

      {active.isError && (
        <div role="alert" className="rounded-md border border-destructive p-4 text-sm">
          {active.error.message}
        </div>
      )}

      {tab === "check" && check.data && <CheckOutcome result={check.data} />}
      {tab === "from" && from.data && <RegionTable regions={from.data} />}
      {tab === "to" && to.data && <SourceTable regions={to.data} />}
    </div>
  );
}

function Field({
  label,
  value,
  onChange,
  placeholder,
}: {
  label: string;
  value: string;
  onChange: (value: string) => void;
  placeholder: string;
}) {
  return (
    <label className="text-sm">
      <span className="block pb-1">{label}</span>
      <input
        className="w-64 rounded-md border px-2 py-1"
        value={value}
        placeholder={placeholder}
        onChange={(event) => onChange(event.target.value)}
      />
    </label>
  );
}

function Unresolved() {
  return (
    <p className="text-sm text-amber-600">
      This result involves an alias that could not be resolved offline, so it may be incomplete.
    </p>
  );
}

function CheckOutcome({ result }: { result: CheckResult }) {
  return (
    <section className="space-y-3 rounded-lg border p-4">
      <p className={`text-2xl font-semibold uppercase ${VERDICT_STYLE[result.verdict] ?? ""}`}>
        {result.verdict}
      </p>
      <p className="text-sm opacity-70">Entered on interface {result.in_interface}</p>
      {result.translated_address && (
        <p className="text-sm">
          NAT rewrote the destination to{" "}
          <code>
            {result.translated_address}:{result.translated_port}
          </code>{" "}
          before the filter ran.
        </p>
      )}
      <p className="text-sm">
        {result.decided_by
          ? `Decided by rule #${result.decided_by.seq} on ${result.decided_by.interface}: ${
              result.decided_by.descr || "(no description)"
            }`
          : "No rule matched — the implicit default deny applied."}
      </p>
      {result.unresolved && <Unresolved />}
      {result.trace.length > 0 && (
        <details className="text-sm">
          <summary className="cursor-pointer">Rules examined ({result.trace.length})</summary>
          <ol className="mt-2 space-y-1">
            {result.trace.map((entry, index) => (
              <li key={index} className={entry.matched ? "" : "opacity-60"}>
                #{entry.rule.seq} {entry.rule.descr || "(no description)"} — {entry.reason}
              </li>
            ))}
          </ol>
        </details>
      )}
    </section>
  );
}

function RegionTable({ regions }: { regions: Region[] }) {
  return (
    <table className="w-full text-left text-sm">
      <thead>
        <tr className="border-b">
          <th className="py-2">Destinations</th>
          <th>Ports</th>
          <th>Verdict</th>
          <th>Decided by</th>
        </tr>
      </thead>
      <tbody>
        {regions.map((region, index) => (
          <tr key={index} className="border-b align-top">
            <td className="py-2">{region.addresses.join(", ")}</td>
            <td>{region.ports}</td>
            <td className={VERDICT_STYLE[region.verdict] ?? ""}>{region.verdict}</td>
            <td>{region.decided_by?.descr ?? "default deny"}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}

function SourceTable({ regions }: { regions: SourceRegion[] }) {
  return (
    <table className="w-full text-left text-sm">
      <thead>
        <tr className="border-b">
          <th className="py-2">Interface</th>
          <th>Sources</th>
          <th>Verdict</th>
          <th>Decided by</th>
        </tr>
      </thead>
      <tbody>
        {regions.map((region, index) => (
          <tr key={index} className="border-b align-top">
            <td className="py-2">{region.in_interface}</td>
            <td>{region.addresses.join(", ")}</td>
            <td className={VERDICT_STYLE[region.verdict] ?? ""}>{region.verdict}</td>
            <td>{region.decided_by?.descr ?? "default deny"}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

```tsx
import { useQuery } from "@tanstack/react-query";
import { useState } from "react";
import { Link, useParams } from "react-router-dom";

import { getAliases, getInterfaces, getNat, getRules } from "@/lib/api";

type Tab = "interfaces" | "aliases" | "rules" | "nat";

const TABS: { id: Tab; label: string }[] = [
  { id: "interfaces", label: "Interfaces" },
  { id: "aliases", label: "Aliases" },
  { id: "rules", label: "Rules" },
  { id: "nat", label: "NAT" },
];

function matches(filter: string, values: (string | number | null | undefined)[]) {
  if (!filter) return true;
  const needle = filter.toLowerCase();
  return values.some((value) => String(value ?? "").toLowerCase().includes(needle));
}

export function InventoryPage() {
  const { configId = "" } = useParams<{ configId: string }>();
  const [tab, setTab] = useState<Tab>("interfaces");
  const [filter, setFilter] = useState("");

  const interfaces = useQuery({
    queryKey: ["interfaces", configId],
    queryFn: () => getInterfaces(configId),
    enabled: tab === "interfaces",
  });
  const aliases = useQuery({
    queryKey: ["aliases", configId],
    queryFn: () => getAliases(configId, true),
    enabled: tab === "aliases",
  });
  const rules = useQuery({
    queryKey: ["rules", configId],
    queryFn: () => getRules(configId),
    enabled: tab === "rules",
  });
  const nat = useQuery({
    queryKey: ["nat", configId],
    queryFn: () => getNat(configId),
    enabled: tab === "nat",
  });

  const searchLink = (source: string) =>
    `/c/${configId}/search?source=${encodeURIComponent(source)}`;

  return (
    <div className="space-y-6">
      <h1 className="text-xl font-semibold">Inventory</h1>

      <div className="flex items-end justify-between gap-4">
        <div role="tablist" className="flex gap-2 border-b">
          {TABS.map((item) => (
            <button
              key={item.id}
              type="button"
              role="tab"
              aria-selected={tab === item.id}
              className={`px-4 py-2 text-sm ${
                tab === item.id ? "border-b-2 font-medium" : "opacity-70"
              }`}
              onClick={() => setTab(item.id)}
            >
              {item.label}
            </button>
          ))}
        </div>
        <label className="text-sm">
          <span className="block pb-1">Filter</span>
          <input
            className="w-64 rounded-md border px-2 py-1"
            value={filter}
            placeholder="IP, network, port, or name"
            onChange={(event) => setFilter(event.target.value)}
          />
        </label>
      </div>

      {tab === "interfaces" && (
        <table className="w-full text-left text-sm">
          <thead>
            <tr className="border-b">
              <th className="py-2">Name</th>
              <th>Device</th>
              <th>Address</th>
              <th>VLAN</th>
              <th>Enabled</th>
            </tr>
          </thead>
          <tbody>
            {(interfaces.data ?? [])
              .filter((row) => matches(filter, [row.name, row.descr, row.ipaddr, row.if_]))
              .map((row) => (
                <tr key={row.name} className="border-b">
                  <td className="py-2">{row.descr}</td>
                  <td>{row.if_}</td>
                  <td>
                    {row.ipaddr && row.subnet !== null ? (
                      <Link className="underline" to={searchLink(`${row.ipaddr}/${row.subnet}`)}>
                        {row.ipaddr}/{row.subnet}
                      </Link>
                    ) : (
                      "—"
                    )}
                  </td>
                  <td>{row.is_vlan ? `${row.vlan_tag} on ${row.parent_if}` : "—"}</td>
                  <td>{row.enabled ? "yes" : "no"}</td>
                </tr>
              ))}
          </tbody>
        </table>
      )}

      {tab === "aliases" && (
        <table className="w-full text-left text-sm">
          <thead>
            <tr className="border-b">
              <th className="py-2">Name</th>
              <th>Type</th>
              <th>Members</th>
              <th>Resolved</th>
            </tr>
          </thead>
          <tbody>
            {(aliases.data ?? [])
              .filter((row) => matches(filter, [row.name, row.descr, ...row.items]))
              .map((row) => (
                <tr key={row.name} className="border-b align-top">
                  <td className="py-2">
                    <Link className="underline" to={searchLink(row.name)}>
                      {row.name}
                    </Link>
                  </td>
                  <td>{row.type}</td>
                  <td>{row.items.join(", ")}</td>
                  <td>
                    {row.error ? (
                      <span className="text-red-600">{row.error}</span>
                    ) : (
                      row.resolved_addresses?.join(", ") ?? row.resolved_ports ?? "—"
                    )}
                  </td>
                </tr>
              ))}
          </tbody>
        </table>
      )}

      {tab === "rules" && (
        <table className="w-full text-left text-sm">
          <thead>
            <tr className="border-b">
              <th className="py-2">#</th>
              <th>Interface</th>
              <th>Action</th>
              <th>Protocol</th>
              <th>Description</th>
              <th>Flags</th>
            </tr>
          </thead>
          <tbody>
            {(rules.data ?? [])
              .filter((row) => matches(filter, [row.descr, row.protocol, ...row.interfaces]))
              .map((row) => (
                <tr key={row.seq} className={`border-b ${row.disabled ? "opacity-50" : ""}`}>
                  <td className="py-2">{row.seq}</td>
                  <td>{row.interfaces.join(", ")}</td>
                  <td>{row.action}</td>
                  <td>{row.protocol}</td>
                  <td>{row.descr}</td>
                  <td>
                    {[row.floating && "floating", row.quick && "quick", row.disabled && "disabled"]
                      .filter(Boolean)
                      .join(", ")}
                  </td>
                </tr>
              ))}
          </tbody>
        </table>
      )}

      {tab === "nat" && nat.data && (
        <div className="space-y-6">
          <section>
            <h2 className="pb-2 font-medium">Port forwards</h2>
            <table className="w-full text-left text-sm">
              <thead>
                <tr className="border-b">
                  <th className="py-2">Interface</th>
                  <th>Protocol</th>
                  <th>Target</th>
                  <th>Local port</th>
                  <th>Description</th>
                </tr>
              </thead>
              <tbody>
                {nat.data.port_forwards
                  .filter((row) => matches(filter, [row.descr, row.target, row.local_port]))
                  .map((row, index) => (
                    <tr key={index} className="border-b">
                      <td className="py-2">{row.interface}</td>
                      <td>{row.protocol}</td>
                      <td>
                        <Link className="underline" to={searchLink(row.target)}>
                          {row.target}
                        </Link>
                      </td>
                      <td>{row.local_port ?? "—"}</td>
                      <td>{row.descr}</td>
                    </tr>
                  ))}
              </tbody>
            </table>
          </section>

          <section>
            <h2 className="pb-2 font-medium">Outbound NAT</h2>
            <p className="pb-2 text-sm opacity-70">
              Shown for reference only. Outbound NAT runs after the filter decision, so it never
              changes whether traffic is allowed.
            </p>
            <table className="w-full text-left text-sm">
              <thead>
                <tr className="border-b">
                  <th className="py-2">Interface</th>
                  <th>Source</th>
                  <th>Destination</th>
                  <th>Target</th>
                </tr>
              </thead>
              <tbody>
                {nat.data.outbound
                  .filter((row) => matches(filter, [row.source, row.destination, row.descr]))
                  .map((row, index) => (
                    <tr key={index} className="border-b">
                      <td className="py-2">{row.interface}</td>
                      <td>{row.source}</td>
                      <td>{row.destination}</td>
                      <td>{row.target}</td>
                    </tr>
                  ))}
              </tbody>
            </table>
          </section>
        </div>
      )}
    </div>
  );
}
```

```markdown
# Frontend Guide

| Version | Date | Changes |
|---|---|---|
| 1.0.0 | 2026-08-10 | Kiến trúc ban đầu: SPA tĩnh, API_URL đọc lúc runtime |

## Stack

Vite, React 18, TypeScript strict, Tailwind, shadcn/ui, Magic UI, TanStack
Query, react-router, `@xyflow/react`. Test bằng Vitest và Testing Library.
Build ra `dist/` tĩnh, nginx serve. Không có node runtime trong production.

## Chạy và test

    cp .env.example .env
    docker compose up -d --build     # production
    npm install && npm run dev       # phát triển
    npm run test                     # test
    npm run lint                     # tsc --noEmit

## Biến môi trường

| Tên | Bắt buộc | Mô tả |
|---|---|---|
| `WEB_PORT` | không | Port host, mặc định 8011 |
| `API_URL` | không | Địa chỉ backend, mặc định `http://localhost:8010` |

`API_URL` được entrypoint ghi vào `/usr/share/nginx/html/config.js` lúc container
start. `index.html` nạp file này trước bundle. Đổi backend chỉ cần sửa `.env`
rồi `docker compose up -d`.

## Quy ước

- **Không** đọc `API_URL` qua `import.meta.env`. Làm vậy nhúng cứng vào bundle
  và phá yêu cầu đổi URL không rebuild. Luôn dùng `src/lib/config.ts`.
- `configId` nằm trong URL (`/c/:configId/...`). Đó là toàn bộ state cần chia sẻ
  giữa các trang; không có store toàn cục.
- Mọi `<button>` trong `<form>` phải có `type` tường minh.
- Magic UI dùng tiết chế. Bảng dữ liệu giữ tĩnh.
- Font tự host trong `public/fonts/`. Không `@import` từ Google Fonts — app phải
  chạy được khi không có internet.

## Gotchas

- `docker compose restart` không nạp lại env. Dùng `up -d` để tạo lại container.
- React Flow đo kích thước container lúc mount. jsdom không có `ResizeObserver`
  và báo mọi element là 0x0, nên `src/vitest.setup.ts` phải stub cả ba thứ:
  `ResizeObserver`, `offsetWidth`, `offsetHeight`. Bỏ đi thì mọi test đồ thị hỏng.
- Backend giữ config trong RAM. Sau khi backend restart, mọi `configId` trong URL
  đều trả 404; các trang hiển thị lỗi đó và người dùng phải upload lại.
```
